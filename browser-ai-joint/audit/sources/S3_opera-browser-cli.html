opera-browser-cli

TypeScript browser automation CLI for Opera

Features

  • open - Open Opera browser
  • click - Click elements on page
  • fill - Fill form inputs
  • screenshot - Capture screenshots
  • chat - Chat with page content
  • invoke-do - Invoke actions
  • make - Create workflows
  • research - Research tasks

Requirements

  • Opera Neon browser installed
  • Signed-in Opera Neon session
  • Node.js 18+

Metadata
